## Commercial use

Commercial use of `spec/`, `adr/` or `meta/` needs a **separate written agreement** with the maintainers. This includes using them as input for AI-assisted generation of commercial software, products or services. To ask, open an issue titled "Commercial licence" at https://github.com/vestacore/river-portal/issues or contact the maintainers through https://github.com/vestacore.

If you are not sure whether your use is commercial, ask us before you start. We want civil-society organisations to be able to use this work.
